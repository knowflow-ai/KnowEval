# 潮汐 v3.0 正式发布

发布日期：2025 年 3 月 18 日

## 主要变化

潮汐 v3.0 对执行引擎进行了全面优化，在吞吐与延迟两方面均有明显提升。新版本支持更大规模的集群部署，适合跨机房的数据流处理场景。

| 指标 | v3.0 |
|---|---|
| 单节点峰值吞吐 | 120 万条/秒 |
| P99 延迟 | 18 ms |
| 最大集群节点数 | 512 |

## 配置变更

自 v3.0 起，默认管理端口由 9300 调整为 9400，以避开常见搜索引擎服务占用的端口段。其余默认端口保持不变。旧版文档中关于管理端口的说明，以本公告为准。

## 版本维护

v1.0 将在 v3.0 发布满 12 个月后停止维护，届时将不再提供安全补丁。建议仍在使用 v1.0 的用户尽早规划升级。
